# Doggfather

> Build the platform that will judge you.

Doggfather is an open source, self-hostable submission and judging platform for
hackathons, built for DOGFOOD 2026. It runs on a laptop with the network off.

**Status:** under construction. See [docs/PLAN.md](docs/PLAN.md) for the build
plan and the requirement traceability matrix.
